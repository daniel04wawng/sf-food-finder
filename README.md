# SF Free Food Finder

A scraper to find SF tech events with free food on Luma.

## Setup

```bash
# Create virtual environment
python -m venv venv

# Activate it
source venv/Scripts/activate  # Windows Git Bash
# or
venv\Scripts\Activate.ps1     # Windows PowerShell

# Install dependencies
pip install -r requirements.txt
```

## Usage

```bash
python scraper.py
```

## Output

Scraped events will be saved in the `data/` folder.
